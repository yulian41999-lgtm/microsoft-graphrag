# 烟金罚决字〔2024〕34号行政处罚详情

## 处罚机构与罚款金额

根据现有资料，**烟金罚决字〔2024〕34号**行政处罚决定所涉及的被处罚机构为**中国工商银行股份有限公司烟台南大街支行**，处罚结果为**罚款35万元** [Data: Sources (0); Entities (1, 2)]。

## 处罚依据与违法事实

该处罚决定由**国家金融监督管理总局烟台监管分局**于**2024年8月8日**作出 [Data: Sources (0); Entities (0, 2)]。被处罚当事人存在的主要违法违规事实为**贷款管理不到位，严重违反审慎经营规则** [Data: Sources (0); Entities (2, 4)]。

行政处罚的法律依据为**《中华人民共和国银行业监督管理法》第二十一条、第四十六条**及相关审慎经营规则 [Data: Sources (0); Entities (3, 10)]。
